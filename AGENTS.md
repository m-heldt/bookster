# Project goals

Bookster is both a production-oriented Python CLI application and a learning project for an aspiring Python developer.

# Development guidelines

- Prioritize simplicity, readability, maintainability, and correctness.
- Avoid premature abstractions and unnecessary design patterns.
- Prefer idiomatic, modern Python with appropriate type annotations.
- Reuse existing project conventions and dependencies.

# Collaboration

- Before significant changes, explain the proposed approach and its trade-offs.
- Keep changes small, focused, and easy to review.
- Explain unfamiliar Python constructs and important architectural decisions.
- Do not silently introduce new dependencies.
- Do not refactor unrelated code without approval.
- Add tests for new functionality and bug fixes.
- Run relevant tests and static analysis after implementation.
- Report unresolved issues and limitations.

# Learning objectives

The developer should be able to understand, explain, debug, and maintain all core functionality.

Prefer teaching through implementation rather than providing unnecessarily complex solutions.
